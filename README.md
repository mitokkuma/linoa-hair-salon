# Linoa hair salon（Web制作サンプル）

美容院サイトのサンプル制作プロジェクトです。店舗名・人物・住所・料金などはすべて架空の情報です。

## フォルダ構成
- `plan.md` … プランシート（ターゲット・目的・セクション構成）
- `wireframe.html` / `wireframe-v2.html` … ワイヤーフレーム
- `mockup.html` / `mockup-v2.html` … デザインモックアップ
- `site/` … **公開用サイト**（Cloudflare Pages の公開ディレクトリ）
- `公開前チェックリスト.md` … 本番運用する場合の差し替え項目

## 公開設定（Cloudflare Pages）
- ビルドコマンド：なし
- 出力ディレクトリ：`site`
